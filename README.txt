WIP SCANNER - PWA

Es una aplicación web progresiva instalable desde Chrome/Edge en Android.

IMPORTANTE:
- Para que la cámara funcione, la aplicación debe publicarse en HTTPS.
- Abrir index.html directamente como archivo local puede impedir el acceso a la cámara.
- En el teléfono: abrir la URL HTTPS, menú del navegador -> "Agregar a pantalla de inicio" / "Instalar aplicación".
- La captura usa BarcodeDetector cuando el navegador lo soporta y está preparada para Code 128.
- El campo "URL de recepción" permite conectar posteriormente el botón ENVIAR con el servicio que registra en Excel.

Campos enviados:
codigo, material, cantidad, lote, ubicacion, fecha_hora, movimiento.
